# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/rsokl/MyGrad/security/advisories/new),
rather than in a public issue. We will acknowledge your report and keep you
updated as we work on a fix.

Fixes are released in the latest version of MyGrad.

Vulnerabilities in NumPy itself should be reported to that project.
